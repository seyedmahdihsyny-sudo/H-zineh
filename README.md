# H-zineh

اپلیکیشن اندروید مدیریت هزینه‌های کارخانه با Expo SDK 58، React Native و Supabase.

## امکانات
- ورود با نام کاربری و رمز عبور؛ ثبت‌نام عمومی در رابط برنامه وجود ندارد.
- ساخت حساب همکار فقط از بخش «مدیریت کاربران» توسط مدیر.
- ثبت هزینه با مبلغ، تاریخ، دسته‌بندی، توضیحات و تصویر فاکتور.
- مشاهده هزینه‌های ثبت‌شده برای کاربران واردشده.
- ویرایش و حذف هر هزینه فقط توسط ثبت‌کننده همان هزینه (با کنترل RLS در دیتابیس).
- تاریخچه تغییرات و اعلان درون‌برنامه‌ای زنده هنگام ثبت هزینه.
- نمایش جمع هزینه‌ها.

## راه‌اندازی در Termux
```bash
cd ~/H-zineh
npm install
npx expo start -c
```

فایل `.env.example` را به `.env` کپی کنید و مقادیر URL و Publishable Key پروژه Supabase را قرار دهید. کلید Publishable برای اپ موبایل مناسب است؛ کلیدهای service_role و secret هرگز نباید داخل برنامه قرار بگیرند.

## ساختار Supabase
- ساختار و سیاست‌های دیتابیس: `supabase/schema.sql`
- تابع Edge برای ساخت کاربر توسط مدیر: `admin-create-user`
- اسکریپت ارتقای حساب اولیه به مدیر: `supabase/bootstrap-admin.sql`

برای فعال‌سازی اولین مدیر، ابتدا حساب Auth با ایمیل داخلی `junior@hzineh.local` را از بخش Auth پروژه ایجاد و سپس اسکریپت `supabase/bootstrap-admin.sql` را در SQL Editor اجرا کنید. پس از آن، ثبت‌نام عمومی را در تنظیمات Auth پروژه غیرفعال کنید.

## امنیت و محدودیت‌ها
- فقط مدیر مجاز به ساخت حساب همکار از طریق Edge Function است.
- مجوز ویرایش/حذف هزینه در دیتابیس با RLS بررسی می‌شود و به رابط کاربری متکی نیست.
- تصاویر فاکتور در bucket خصوصی `invoices` نگهداری می‌شوند.
- اعلان فعلی درون‌برنامه‌ای و زنده است؛ Push Notification سیستمی و اعلان انتشار نسخه جدید هنوز پیاده‌سازی نشده‌اند.
