# H-zineh

اپلیکیشن اندروید مدیریت هزینه‌های کارخانه با Expo React Native و Supabase.

## امکانات نسخه پایه
- ثبت‌نام و ورود کاربران
- ثبت هزینه با مبلغ، تاریخ، دسته‌بندی و توضیحات
- پیوست تصویر فاکتور در فضای ذخیره‌سازی خصوصی
- مشاهده هزینه‌های ثبت‌شده برای اعضای واردشده
- ویرایش و حذف فقط برای ثبت‌کننده همان هزینه (با RLS دیتابیس)
- ثبت تاریخچه تغییرات
- اعلان درون‌برنامه‌ای عمومی هنگام ثبت هزینه جدید
- نمایش جمع هزینه‌ها

## راه‌اندازی
1. Node.js نسخه LTS را نصب کنید.
2. وابستگی‌ها را نصب کنید: `npm install`
3. فایل `.env.example` را به `.env` کپی کنید.
4. مقدار `EXPO_PUBLIC_SUPABASE_ANON_KEY` را با کلید Publishable پروژه جایگزین کنید.
5. اجرا: `npx expo start`

## امنیت
- فقط کلید Publishable در برنامه موبایل استفاده شود؛ کلید service_role یا secret هرگز نباید وارد برنامه شود.
- تصاویر فاکتور در bucket خصوصی `invoices` ذخیره می‌شوند.
- ساختار دیتابیس در `supabase/schema.sql` قرار دارد و روی پروژه متصل اعمال شده است.

## وضعیت
گزارش PDF/Excel و اعلان Push سیستمی در نسخه بعدی توسعه داده می‌شوند؛ اعلان نسخه فعلی درون‌برنامه‌ای و زنده است.
